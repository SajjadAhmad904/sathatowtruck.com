# سطحة جدة | Satha Tow Truck

موقع ثابت (React + TypeScript) لخدمة سطحة هيدروليك جدة.

- الموقع: https://sathatowtruck.com/
- الجوال: 0580836027

## الصفحات

| المسار | الصفحة |
|--------|--------|
| `/` | الرئيسية |
| `/services` | جميع الخدمات |
| `/services/emergency-roadside` | سحب طوارئ على الطريق |
| `/services/hydraulic-flatbed` | ساطحة هيدروليك للسيارات |
| `/services/luxury-sports` | نقل سيارات فاخرة ورياضي |
| `/services/motorcycle-scooter` | سحب دراجات وسكوتر |
| `/services/fleet-commercial` | أساطيل وتجاري خفيف |
| `/services/intercity` | نقل سيارات بين المدن |
| `/about` | من نحن |
| `/contact` | اتصل بنا |

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

المخرجات في مجلد `dist/` جاهزة للرفع على أي استضافة ثابتة.
